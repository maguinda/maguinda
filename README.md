## 🚀 Proyectos destacados

### 🛍️ Artesanías Colombianas — E-commerce full-stack
Plataforma de venta de artesanías colombianas en producción. → [Ver repositorio](https://github.com/maguinda/artesanias-colombianas)
- **Stack:** Node.js/Express · React + Vite · MySQL · Railway · Cloudflare
- Pasarela de pagos con **CyberSource**
- Emails transaccionales por estado de pedido (**Brevo**)
- Búsqueda en tiempo real con *debounce* y sistema de notificaciones persistente
- ⚡ **Mejora de rendimiento de 47x** en el backend eliminando una llamada externa innecesaria

### 🏢 Eventify — Gestión de asambleas y propiedad horizontal
Aplicación full-stack desplegada en servidor propio.
- **Stack:** Node.js · React · MySQL 8 · Sequelize · PM2 · Nginx · SendGrid
- Despliegue y administración en **DigitalOcean (Ubuntu)**
- Carga masiva desde Excel, flujo de verificación de despliegues y manual de despliegue documentado

### 🤖 Detección de Fraude en Pagos para Pymes (en curso)
Proyecto académico de **IA aplicada** a la detección de fraude en transacciones de e-commerce para pequeñas empresas, con validación de un consultor de riesgo del sector de pagos.

### 🏗️ Nexus Safe-Cloud — Arquitectura de ERP SaaS
Diseño de arquitectura de software para un ERP multiplataforma y multisede: centralización de datos, dashboards e informes, modelo SaaS.
